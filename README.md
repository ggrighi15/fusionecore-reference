# FusioneCore Suite Reference

Site de referência completo e navegável para o **FusioneCore Suite** - ERP Jurídico com Governança Real.

## 🎯 Sobre

Este site contém a documentação completa do FusioneCore Suite, um ERP jurídico completo com camada de inteligência que organiza:

- **Contencioso** - Processos e contingências
- **Contratos e Documentos** - Extração, análise e pareceres
- **Procurações** - Controle e alertas
- **Patrimonial** - Imóveis, consórcios e investimentos
- **Cobranças e Demandas** - Solicitações internas
- **Auditoria e Circularização** - Trilha completa
- **Painéis Interativos** - Dashboards navegáveis
- **Automação** - IA, e-mails e alertas

## 🚀 Tecnologias

- **React 19** - Framework frontend
- **Vite 6** - Build tool
- **Tailwind CSS 4** - Estilização
- **Wouter** - Roteamento
- **Lucide React** - Ícones

## 🎨 Identidade Visual

- **Cores Primárias:** Preto (#000000) + Verde Limão (#CDFF00)
- **Cores Secundárias:** Cinzas (#2B3A4A, #4A5568, #718096)
- **Tipografia:** Poppins (títulos) + Inter (corpo)

## 📋 Funcionalidades

- ✅ Navegação estruturada por módulos
- ✅ Sistema de busca em tempo real
- ✅ Documentação completa de 8 módulos
- ✅ Arquitetura técnica detalhada
- ✅ Roadmap de implementação (6 fases)

- ✅ Capacidades de IA/LLM
- ✅ Design responsivo (desktop, tablet, mobile)

## 🛠️ Desenvolvimento

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Build para produção
npm run build

# Preview do build
npm run preview
```
